# QA checklist

- [ ] `bun install` по lockfile, `bunx tsgo --noEmit`, `bunx eslint src`, `bunx vitest run`, production build
- [ ] Все маршруты открываются: / onboarding servers servers/$country server/$id scan subscriptions subscriptions/$id rules rules/apps rules/whitelist rules/blacklist rules/domains rules/limited favorites compare statistics diagnostics events settings about
- [ ] Телефон 360–430 px: нижняя навигация, ничего не обрезается; планшет ≥768 px: боковая панель
- [ ] Тёмная / светлая / системная тема; RU / EN; «уменьшить движение»
- [ ] Подключение DEMO: диалог разрешения, фазы, отмена, отключение, сессия в статистике
- [ ] Сканирование: старт, прогресс, отмена, группы результатов, подключение к найденному
- [ ] Подписки: URL (валидация, SSRF-блок, CORS-ошибка объяснена), URI-вставка, TXT, буфер; история; удаление сохраняет избранное
- [ ] Экспорт: предупреждение, копирование URI, TXT, JSON, QR, экспорт выбранных и подписки
- [ ] Белый/чёрный список: поиск, фильтры, выбрать все, сброс, импорт/экспорт, подтверждение
- [ ] Домены/IP: добавление/правка/удаление, валидация, приоритет, конфликты, импорт/экспорт TXT/JSON
- [ ] Ограниченная связь: сохранение, резервная копия, текст ограничений
- [ ] Диагностика: DNS/IPv4/IPv6, отчёт без секретов
- [ ] Перезагрузка страницы сохраняет настройки, правила, подписки
- [ ] Все DEMO-значения помечены; нигде не заявлен реальный туннель
